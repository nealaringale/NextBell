## Important import boundary

This file is a human-readable transcription of the printed cell labels. It deliberately
does not claim that every cell has already been converted into a tested time-bounded
event. Several sheets contain merged cells, parallel batch rows, and roll-based
tutorial/library splits. Those must be mapped from the actual grid before they can drive
the app's Home, Week, Attendance, widget or notification features. Do not publish these
as live schedules until the event data is checked against the official sheet.
