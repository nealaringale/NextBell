Get started

Install in a few steps.

1

Download the APK

Tap Download for Android and wait for the file to finish downloading.

2

Allow this install source

Open the downloaded file. Android may ask you to allow your browser or file manager to install apps.

3

Install and open NextBell

Tap Install, then open NextBell from your app screen.

Important: this is a test build

NextBell is shared here as a directly installed Android debug/testing APK, not through the Play Store. Android may show a security warning for apps installed from outside the Play Store. Only install it if you are comfortable testing this build.
